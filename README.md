# EPL Forwards: Goals vs xG Scatter Analysis (2024/25)

## Question
Which EPL forwards were the most clinical finishers and most 
wasteful in the 2024/25 season?

## Data
FBRef Premier League 2024/25 player statistics.
77 forwards · 900+ minutes filter applied.

## Methodology
- Filtered dataset to forwards with 900+ minutes played
- Plotted Goals per 90 vs xG per 90 for every forward
- Added diagonal reference line where Goals = xG
- Forwards above the line scored more than expected (clinical)
- Forwards below the line scored less than expected (wasteful)
- Highlighted top 5 and bottom 5 performers

## Key Findings
- Bryan Mbeumo was the most clinical finisher — consistently 
  scoring well above his xG per 90
- Eddie Nketiah was the most wasteful — getting into good 
  positions but failing to convert
- Most forwards cluster close to the reference line — 
  true clinical outliers are rare
